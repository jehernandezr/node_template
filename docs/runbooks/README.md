# Runbooks

Procedimientos para operar la plataforma. Cada uno dice cuándo se usa, qué mirar antes, los pasos y cómo saber que terminó.

| Runbook                                                           | Cuándo                                                                       |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| [Operación de los servicios](operacion-de-servicios.md)           | Revisar salud, jobs, colas, DLQ y configuración de cualquier servicio        |
| [Traslado de un tenant](traslado-de-tenant.md)                    | Mover un tenant a otro grupo de shards o a otra región                       |
| [Rotación de las claves de identity](rotacion-claves-identity.md) | Rotar las claves de firma de los access tokens                               |
| [Rotación de secretos de servicio](rotacion-de-secretos.md)       | Rotar el secreto de la API interna, las pimientas o las credenciales de base |
