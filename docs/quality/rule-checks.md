# Rule checks

Every rule of [CLAUDE.md](../../CLAUDE.md) and of the skills in [.claude/skills](../../.claude/skills), next to the check that enforces it. A rule marked `review only` has no automatic check: the reviewer enforces it, and a finding about it is closed with the guard that the finding adds (lint rule, structure check, language check or test).

`.claude/guards/__tests__/rule-checks.test.mjs` fails when a rule has no row here or a row names a rule that no longer exists. A row names its rule by the first words of the bullet.

Where the checks run:

- **Pre-commit**: lint-staged runs ESLint (backend rules and guards, tooling comment rules), the language check on staged files and the structure checks.
- **`commit-msg`**: commitlint and the language check of the message.
- **CI**: the `guards` job (language check, tool tests, structure checks, tooling lint) and the `nx` job (lint, typecheck, tests, contracts, generators); `ci-ok` requires both.
- **Workflow gate**: `.claude/guards/run-gate.mjs`, which `phase-cycle.js` runs before every review.
