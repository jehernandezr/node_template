# contracts

Dart for the backend contracts, for the front. A pure Dart package.

- `lib/src/core/`: hand-written core. `RouteDescriptor` and `encodeQuery`, `ProblemDetails` and `FieldError` (RFC 9457), `ApiErrorException`, `ContractViolationException`, validation and equality.
- `lib/src/<service>/`: code generated by `front/tools/contracts_gen` from `backend/libs/contracts/*/export/contract.json` (ADR 0017): enums, constants, types, validators, routes and messages. It is not edited by hand; `dart run contracts_gen --check` fails if it is out of date.

`test/platform_error_code_sync_test.dart` checks that every public code has a message in `i18n`.
